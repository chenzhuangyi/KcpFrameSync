确认 token 已填入后，点下面蓝色的「② 连接并对局」

		
		
		
token 由 server.lua 每次启动随机生成，旧日志里的 token 不能用；
			先点「① 读取当前 token」（经网关从 Docker 读 tokens_<房间ID>.txt），再点「② 连接并对局」。

			单人房（server.lua 1 1）只需 conv=101；多人房每个标签页填不同 conv/token。

			注意：默认连容器内网关 18080（不依赖 Docker 的 UDP 端口代理，最稳定）；
			如果你在本机跑 node gateway.js，把地址改成 ws://127.0.0.1:8081。
			不要填服务器的 10500（那是 UDP 端口，由网关去连）。
